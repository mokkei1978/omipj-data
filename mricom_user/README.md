mricom_user_pack サンプル入力データ (mricom_user_pack)
========

MRI.COMユーザーパッケージの描画Pythonスクリプトをテストするための
サンプル入力データファイル。
https://github.com/mokkei1978/mricom_user_pack/


内容
--------

* japan_sea/        - 日本海解析
  - himsst.*          - HIMSST netCDF
* rectangle/        - MRI.COM矩形海モデル
  - wind_x.gd         - x方向風応力 (MRI.COM-rectのデフォルト設定)
